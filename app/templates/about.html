About This Project

Final-year dissertation: machine learning for cardiovascular risk awareness.

  • Project Aim: Predict whether a person is likely at cardiovascular risk using common health indicators.
  • Dataset: UCI Heart Disease dataset (Cleveland processed version).
  • Algorithms: Logistic Regression and Random Forest.
  • Tools: Python, Flask, scikit-learn, pandas, SQLite.
  • Evaluation Metrics: Accuracy, Precision, Recall, F1-score.
This application is designed for academic and educational demonstration. It is not a medical diagnosis system.
